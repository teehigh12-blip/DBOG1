HOW TO EDIT LATER
1. Open index.html in any HTML/text editor.
2. Edit the visible text you want to change.
3. Replace or add photographs inside the assets folder.
4. Keep the same file names if you are replacing an existing photograph, or update the matching image filename in index.html.
5. Upload/deploy the complete DBOG_final folder (not just index.html) when publishing a new version.

IMPORTANT
Do not delete the assets folder when uploading. The website needs the logo, photos, CSS and JavaScript files from that folder/package.
